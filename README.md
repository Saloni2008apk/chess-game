
# ♟️ Chess Master — Play Chess Online

A simple, interactive chess game built using HTML, CSS, and JavaScript. Play chess with a friend on the same device using a responsive chessboard and real chess rules.

## 🚀 Features

- ♟️ Classic 8×8 chessboard with all 32 pieces.
- 🎯 Legal move highlighting.
- 👑 Check and checkmate detection.
- 🔄 Undo moves and restart the game.
- 🔀 Flip the board for either player's perspective.
- ♕ Pawn promotion to queen, rook, bishop, or knight.
- 📜 Move history for both players.
- 📱 Responsive design for mobile and desktop.
- ⚖️ Special moves, including castling and en passant, supported by chess.js.

## 🛠️ Technologies Used

- **HTML5** — Website structure.
- **CSS3** — Styling and responsive layout.
- **JavaScript** — Game logic and interactions.
- **chess.js** — Chess rules and legal move validation.

## 🎮 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure all three source files are saved in the same folder.
4. Connect to the internet to load the chess.js library.
5. Open `index.html` using the VS Code Live Server extension.
6. Start playing!

## 🕹️ How to Play

1. Click one of your pieces.
2. Select a highlighted square to make a legal move.
3. Players alternate turns between White and Black.
4. Use **Undo Move** to take back a move.
5. Use **New Game** to restart.
6. Use **Flip Board** to change the board's orientation.
